# QC User Archetypes

Generated archetype files live here. Each file covers one QC user segment.

| File | Segment | Status |
|------|---------|--------|
| `ntqc-archetype.md` | New to QC | Run `/fp-create-qc-archetype` to generate |
| `light-qc-archetype.md` | Light QC | Run `/fp-create-qc-archetype` to generate |
| `active-qc-archetype.md` | Active QC | Run `/fp-create-qc-archetype` to generate |

## How to generate

1. Open Claude Code
2. Type `/fp-create-qc-archetype`
3. Select the segment
4. Provide your Google Drive research folder link
5. Claude will generate the archetype and save it here

## How to use

1. Type `/fp-use-qc-archetype`
2. Select which archetype(s) to load
3. Chat with Claude as that user persona

## Confidence scoring

- **Gold** — ≤ 30% assumption-based statements. Safe for design feedback and team alignment.
- **Silver** — 31–50% assumption-based. Useful for hypothesis generation; flag gaps to stakeholders.
- **Insufficient** — > 50% assumption. Do not use; gather more research first.
